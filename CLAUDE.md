# model-family-tree

Nightly-rebuilt ancestry graph of every Hugging Face model. Only `data/families.yaml` and code are hand-edited; `README.md`, `dist/`, `docs/tables/`, `assets/` are generated by `scripts/build.py`.

- Build from cache: `uv run python scripts/build.py build --date YYYY-MM-DD` (about 10 s). Full: `scripts/build.py all` (1.6 GB download).
- Tests: `uv run pytest`.
- MCP server: `mcp/server.py` (tools lineage, children, leaderboard, family, search, stats). Live HF API for ancestors/children, dist/ for counts.
- Site: `site/` static, D3 vendored; reads `dist/*.json` and the HF API directly.
- Never commit `.cache/`.
